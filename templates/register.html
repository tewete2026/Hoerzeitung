Erläuterungen

  1. Wenn Sie einen Freischaltcode per E-Mail von uns erhalten haben:

    Bewahren Sie den von uns erhaltenen Freischaltcode unbedingt auf. Geben Sie den Freischaltcode oben links in dem dafür vorgesehenen Eingabefeld ein und klicken auf "Freigabe erteilen". Danach werden Sie automatisch weitergeleitet zur Übersicht der Episoden der Hörzeitung. Beachten Sie, dass die Eingabe des Codes verdeckt erfolgt, damit Ihr Browser (z.B. Firefox, Safari, Chrome) den Code als Passwort behandelt und Sie fragt, ob das Passwort gespeichert werden soll (abhängig von Ihren Browser-Einstellungen zur Daten-Sicherheit). Die Speicherung wird empfohlen, dadurch wird das Feld bei erneutem Aufruf dieser Webseite automatisch gefüllt.
    Weiterhin wird dieser Code als sogenanntes "Cookie" in Ihrem Browser ein Jahr lang gespeichert, damit Sie in Zukunft den Code nicht erneut eingeben müssen. Damit Ihr Browser dieses Cookie nicht wieder löscht, können Sie in Ihren Browser-Einstellungen die Internetadresse dieser Webseite in die Ausnahmen verwalten - Cookies und Website-Daten beim Beenden von Firefox löschen als "nicht löschen" eintragen.

  2. Wenn Sie KEINEN Freischaltcode erhalten haben, aber die DRK-Norderstedter-Hörzeitung hören möchten:

    Einen Freischaltcode bekommen Sie nur, wenn Sie uns einen Nachweis Ihrer Sehbehinderung an dieser Stelle mitsenden. Geben Sie oben rechts in den Feldern Ihre Kontaktdaten ein, wählen Sie ein Dokument zum Nachweis Ihrer Sehbehinderung aus und klicken auf "Absenden". Wir werden uns dann mit Ihnen in Verbindung setzen. Die Freischaltung für die Inhalte ist kostenfrei.
